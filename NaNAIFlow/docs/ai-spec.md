# Product Intent

Describe the business goal in 2-5 lines.

Example:
Create a landing page for an automation SaaS focused on trust and conversion.

# UI Direction

- Brand tone and audience
- Typography choices (avoid default stacks)
- Color palette and visual style
- Motion guidance
- Accessibility and responsive priorities

# Technical Constraints

- Framework and tooling
- Folder constraints
- Forbidden libraries or patterns
- Performance targets

# Definition of Done

- Functional outcomes
- UI sections that must exist
- Test/build commands that must pass
- Manual acceptance notes
